# Prompts utiles

Ejemplos de prompts que puedes adaptar:

```text
Quiero crear un visor web 3D de una vivienda. Revisa el proyecto, separa datos privados de datos publicables y genera una version demo sin informacion personal.
```

```text
Construye un contrato world.json para mi visor: habitaciones, puntos de aparicion, colisiones, mobiliario seleccionable y parametros de persona de 1,80 m.
```

```text
Verifica que el visor carga, que no hay errores de consola, que se puede recorrer con WASD, medir dos puntos y usarlo en movil.
```

No pegues en prompts publicos direcciones, escrituras, emails, telefonos, documentos o imagenes que identifiquen tu vivienda.
