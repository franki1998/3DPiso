# Flujo general

El objetivo es pasar de un plano o modelo 3D a una web que otra persona pueda abrir desde un enlace.

1. Reunir referencias: plano, superficies y medidas oficiales disponibles.
2. Definir una escala fiable. No uses muebles como regla salvo que no tengas otra opcion.
3. Reconstruir la vivienda en Blender con metros reales.
4. Separar arquitectura, mobiliario y colisiones.
5. Exportar varios GLB ligeros y un `world.json`.
6. Probar navegacion, puntos de aparicion, medicion y movil.
7. Publicar con Vercel, Netlify, GitHub Pages u otro hosting estatico.

Para proyectos privados, guarda el piso real en un repositorio privado y publica solo una plantilla o demo ficticia.
